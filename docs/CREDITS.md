## Fonts

- **Builder Sans** (`Enum.Font.BuilderSans*`): Roblox's own UI font, licensed for use in Roblox experiences ([Builder Font License](https://create.roblox.com/docs/resources/builder-font-license)). Body, medium and bold text.
- **Fredoka One** (`Enum.Font.FredokaOne`): by Milena Brandão, SIL Open Font License 1.1, built into Roblox. Display text (big numbers, "You won", the primary button).
- **Gotham** (`Enum.Font.Gotham*`): Roblox's built-in font, the fallback if the fonts above are missing.
